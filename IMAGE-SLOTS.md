# Image slots

Generated by `npm run build` (or `npm run images:report`) on 2026-10-12.

**How it works.** Every picture on the site has a *slot key*. To use a real photograph, save it as `public/images/<slot key>.jpg` (or .png / .webp / .avif) — it replaces the sample picture or the placeholder automatically at the next build. Nothing in the code changes.

* **Recommended size** = twice the widest display size (retina). JPG, sRGB, quality 80–85. The build makes 480 / 960 / 1600 px WebP variants itself (needs `sharp`).
* **Ratio** = the crop the layout uses. The picture is cropped to it (`object-fit: cover`), so keep the subject in the middle third; the focal point per product is set in `src/content/catalog.ts` (`pos`).
* Pictures of objects on a ground (Scan Series) are shown *whole* on a paper ground; shoot them on a neutral background.
* **Status**: `local` = a file you put there · `stripe` = picture on the Stripe product · `sample picture` = stand-in shipped with the code · `EMPTY` = placeholder.
